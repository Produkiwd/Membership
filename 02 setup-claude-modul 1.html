Custom Instructions

Ceritakan sekali siapa Anda. Claude ingat di setiap percakapan baru.

Kenapa Perlu Di Mana Contoh Mulai Simple Before · After
Kenapa Perlu

Tanpa ini, Claude tidak tahu siapa Anda.

Bayangkan setiap hari Anda harus memperkenalkan diri ulang ke asisten yang sama — nama, pekerjaan, cara kerja Anda. Buang waktu. Custom Instructions mengisi informasi itu sekali untuk semua sesi.

Analoginya
"Ini seperti briefing 15 menit ke asisten baru — tapi cukup dilakukan sekali."
Di Mana Settingnya
Cara Akses — Desktop App
Settings → General
1Buka Claude desktop app
2Klik nama profil → pilih Settings
3Tab General → cari "Instructions for Claude"
4Isi kotak teks — tersimpan otomatis
Isi dua kolom ini
Instructions for Claude — isi dengan ini

Satu kotak teks. Isi dengan 3 bagian: Siapa Anda, cara Claude merespons, dan apa yang tidak Anda inginkan. Pakai template di bawah.

Contoh Sederhana — Kehidupan Sehari-hari
Pertanyaan: "Buatkan cerita pendek untuk anak tidur malam ini."
Tanpa Custom Instructions, Claude tidak tahu apakah anak Anda berusia 3 tahun atau 10 tahun, suka dinosaurus atau putri, butuh cerita 2 menit atau 10 menit.
Tanpa Setup tidak ada custom instructions
A
Buatkan cerita pendek untuk anak tidur malam ini.
C
Tentu! Berikut cerita pendek untuk anak: "Si Kelinci dan Bintang" Di sebuah hutan yang damai, hiduplah seekor kelinci bernama Kiki. Setiap malam, Kiki suka memandang bintang sebelum tidur... [cerita berlanjut 300 kata, generic, tidak disesuaikan]
Dengan Setup CI: "anak perempuan 5 tahun, suka kucing"
A
Buatkan cerita pendek untuk anak tidur malam ini.
C
"Mimi si Kucing dan Bulan" Mimi, kucing oranye berbulu lembut, punya satu kebiasaan malam: bertanya pada bulan. "Bulan, kenapa kamu bulat?" tanya Mimi. "Supaya bisa menyinari semua rumah sekaligus," jawab bulan pelan. Mimi mengangguk. Lalu melingkar di selimut, dan tidur. — 2 menit baca, cocok untuk usia 5 tahun —
Framework — 4 Blok Brief
Blok 01 · Siapa

Identitas

Jabatan, industri, skala tanggung jawab, siapa yang sering Anda hadapi.

Contoh isian
Direktur Operasional, logistik FMCG, 200 karyawan
Audience: direksi, klien korporat, ops manager
Tanggung jawab: 3 divisi, P&L, vendor relations
Blok 02 · Kerja

Fokus Kerja

Apa yang paling sering dikerjakan dan cara Anda berpikir tentangnya.

Contoh isian
Review kontrak, negosiasi vendor, keputusan operasional cepat
Sering kerja dengan data tidak lengkap
Judgment > analisis panjang
Blok 03 · Gaya

Format Output

Panjang, tone, bahasa, dan urutan penyajian yang paling cocok untuk Anda.

Contoh isian
Jawaban maks 5 poin. Daftar, bukan paragraf.
Bahasa Indonesia. Formal tapi tidak kaku.
Kesimpulan dulu, detail kalau diminta.
Blok 04 · Batas

Yang Tidak Mau

Hal-hal yang membuat output terasa tidak relevan atau membuang waktu Anda.

Contoh isian
Jangan: feedback grammar, lebih dari 1 pertanyaan
Jangan: basa-basi pembuka atau "Tentu saja!"
Jangan: jawaban 500 kata untuk pertanyaan singkat
2 Kalimat yang Mengubah
"Kalau saya minta review email atau dokumen, fokus pada risiko makna dan kejelasan pesan — bukan grammar."
Claude berhenti komentar typo dan tata bahasa. Langsung ke apa yang benar-benar penting: apakah pesan sampai dengan benar.
"Jawaban panjang artinya kamu belum cukup berpikir. Ringkas dulu — elaborasi hanya kalau saya minta."
Claude berhenti memberi respons 500 kata untuk pertanyaan yang jawabannya 3 kalimat.

Projects

Custom Instructions bilang siapa Anda. Projects bilang apa yang sedang Anda kerjakan.

Kenapa Perlu 3 Template Connectors Memory
Kenapa Perlu

Setiap chat baru = Claude lupa konteks.

Claude tidak menyimpan isi percakapan dari satu chat ke chat lain. Jadi kalau Anda punya proyek yang sedang berjalan — rekrutmen, strategi, klien tertentu — Anda harus menjelaskan konteksnya ulang di setiap chat baru. Projects menghilangkan itu.

Tanpa Projects, pilihan Anda:
(a) Tulis panjang konteks di setiap prompt
(b) Pakai satu chat panjang yang makin berantakan
(c) Lupakan detailnya — hasilnya tidak optimal
Bedanya dengan CI
"CI = kartu identitas Anda. Projects = folder kerja dengan semua dokumen dan konteks yang Anda butuhkan untuk area kerja tertentu."
Di Mana Membuat Project
Cara Buat Project Baru
Projects → New project
1Klik Projects di sidebar kiri
2Tombol New project pojok kanan atas
3Isi nama project + deskripsi tujuan → Create project
4Di dalam project: tambah Instructions dan upload dokumen
Apa yang bisa dimasukkan
Project Instructions
Konteks tetap: nama project, tujuan, constraint, cara Anda ingin Claude membantu di area ini. Pakai 4 Blok Brief.
Dokumen Upload
File yang sering Anda rujuk: JD, brief klien, data, template, OKR. Claude bisa membaca dan menjawab berdasarkan isinya.
Aturan upload: Masukkan hanya yang perlu dibaca anggota tim baru di hari pertama untuk langsung bisa membantu.
Contoh Sederhana — Rencana Liburan
Tanpa Project chat baru, mulai dari nol
A
Rekomendasikan resto untuk makan malam besok.
C
Di mana lokasinya? Berapa budget per orang? Preferensi makanan apa? Ada yang alergi? Untuk berapa orang? Mohon berikan informasinya agar saya bisa membantu...
Dengan Project "Liburan Bali"
A
Rekomendasikan resto untuk makan malam besok.
C
Untuk 4 orang di Seminyak malam Sabtu, budget ~Rp 300rb/orang: Sarong Restaurant — fine dining tapi worth it, book dulu. Métis — French-Indonesian, ambience bagus, cocok untuk anniversary. Sea Circus — lebih santai, seafood fresh, cocok kalau ada anak. Sarong paling sesuai brief kalian. Mau saya bantu reservasi?

Before · After — Konteks Kerja
Tanpa Project chat baru
A
Siapkan pertanyaan interview untuk kandidat senior manager besok.
C
Berikut 10 pertanyaan interview untuk posisi senior manager: 1. Ceritakan pengalaman memimpin tim besar 2. Bagaimana menghadapi konflik tim? 3. Apa pencapaian terbesar Anda? ...
Dengan Project "Rekrutmen Q3" + CV Dian
A
Siapkan pertanyaan interview untuk kandidat senior manager besok.
C
Dari CV Dian, dua hal perlu dikonfirmasi: Gap kritis: Semua pengalaman single-site. Posisi ini butuh multi-site. → "Di [perusahaan], koordinasi tim lintas lokasi seperti apa?" Ada 8 bulan 2022 tidak dijelaskan. → "Di periode itu, Anda fokus di mana?" Culture fit: → "Keputusan apa yang Anda buat dengan data tidak lengkap?" Mau saya siapkan untuk interviewer lain juga?
Exercise · Modul 02

Buat Project Pertama

1
Pilih satu area kerja yang paling sering Anda gunakan Claude — tim, rekrutmen, klien, atau project aktif.
2
Di Claude, klik Projects → + New Project. Beri nama yang spesifik.
3
Isi Project Instructions dengan 4 Blok Brief — tapi tentang konteks area kerja ini, bukan tentang Anda.
4
Upload 1 dokumen yang paling sering Anda rujuk dalam pekerjaan ini.
5
Test: tanya sesuatu yang butuh konteks dari dokumen itu. Perhatikan bedanya.

Templates

Simpan pola kerja yang berulang. Hubungkan Claude ke data Anda.

Kenapa Perlu Di Mana Contoh 4 Blok 2 Kalimat Template
Kenapa Perlu

Pola kerja yang sama, mulai dari nol terus.

Setiap kali bikin meeting summary, rekap notulen, atau draft komunikasi — Anda tulis instruksi yang hampir sama. Template menyimpan instruksi itu. Tinggal paste konten, hasilnya konsisten.

Claude tidak bisa akses data Anda — kecuali dihubungkan.

Tanpa Connector, Anda harus copy-paste dari Notion, Drive, atau Gmail ke Claude. Dengan Connector, Claude langsung membaca dari sumber Anda.

Butuh desktop app (gratis)
3 Template Siap Copy-Paste
Meeting Summary
Ini notulen/rekaman rapat saya: [paste atau upload] Buat: 1. Keputusan yang diambil (hanya yang final) 2. Action items: SIAPA — APA — KAPAN 3. Yang masih terbuka dan perlu follow up Format: singkat, langsung bisa dikirim ke peserta.
Analisis Keputusan
Saya perlu memutuskan: [deskripsi keputusan] Konteks: - Situasi saat ini: [ringkasan singkat, 2-3 kalimat] - Pilihan yang ada: [opsi A / opsi B / opsi C] - Batasan: [budget / waktu / SDM] - Siapa yang terdampak: [tim / klien / pihak terkait] Bantu saya: 1. Asumsi tersembunyi yang mungkin terlewat 2. Risiko terbesar tiap pilihan 3. Satu pertanyaan yang perlu dijawab sebelum memutuskan
Draft Komunikasi
Saya perlu kirim [email / pesan / memo] ke: [nama penerima + jabatan] Poin yang perlu disampaikan: [bullet 2-4 poin utama] Tone: [tegas / update rutin / minta persetujuan / bad news] Panjang: [singkat <150 kata / sedang / detail] Satu draft terbaik. Saya akan edit yang perlu disesuaikan.

Memory — Ingatan Lintas Sesi

Template bisa hidup di tiga tempat

Template yang Anda buat tidak harus disimpan manual setiap kali. Claude punya tiga cara menyimpan konteks.

01 · File MD di Project

Buat file prompt-templates.md di dalam Project. Template tersimpan permanen dan bisa diakses dari chat mana pun dalam project itu.

02 · Memory (Desktop App)

Di akhir percakapan yang menghasilkan sesuatu berguna — minta Claude: "Simpan ini ke Memory." Claude akan ingat di sesi berikutnya.

03 · Upload MD ke Chat Baru

Export hasil kerja sebagai file .md, lalu upload ke sesi berikutnya. Cara paling portabel — bisa dibawa ke Claude versi apapun.

Cara Pakai Memory
A
Simpan ke Memory: cara saya menulis email ke klien korporat — to the point, tanpa basa-basi, bullet bila perlu.
C
Tersimpan. Di sesi berikutnya, saya akan otomatis menulis email Anda dengan gaya ini.
Akses Memory
Settings → Memory → lihat dan kelola semua yang Claude ingat tentang Anda.
Aturan Praktis
Gunakan Project untuk konteks pekerjaan spesifik. Gunakan Memory untuk preferensi gaya kerja yang berlaku di semua chat. Gunakan file .md bila ingin portabel atau berbagi dengan orang lain.
